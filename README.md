# Voice Leader

Tonlinien über Jazz-Akkordfolgen finden: Akkorde als drehbare Ringe wie bei einem Zahlenschloss, Wiedergabe mit Klavier oder Saxophon.

Die App läuft im Browser und lässt sich auf dem iPad (Safari: Teilen → Zum Home-Bildschirm) und auf dem Mac (Safari: Ablage → Zum Dock hinzufügen) wie eine App installieren. Nach dem ersten Öffnen funktioniert sie auch offline.

## Klänge

- Klavier: Salamander Grand Piano von Alexander Holm, CC BY 3.0
- Saxophone: MusyngKite-Soundfont über midi-js-soundfonts von Benjamin Gleitzman, CC BY-SA 3.0
